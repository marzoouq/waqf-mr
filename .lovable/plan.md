# خطة محقَّقة على الأرض — تنظيف الاختصاصات للوحات الأربع

تم فحص الصفحات الفعلية والمكونات قبل التعديل. النتائج تُعدّل الخطة السابقة كما يلي:

## نتائج التحقق على الكود (ملاحظات حاسمة)

| اللوحة | الحالة الفعلية | الأثر على الخطة |
|---|---|---|
| **لوحة المستفيد** (`BeneficiaryDashboard`) | نظيفة أصلاً: 3 بطاقات فقط (حصتي، آخر توزيع، السنة المالية) + روابط سريعة + توزيعات حديثة + إشعارات | **لا تغيير** على اللوحة. التعديل يقتصر على `PropertiesViewPage` المستفيد. |
| **لوحة المحاسب** | تستخدم نفس `AdminDashboard` + فلتر `accountant-dashboard-filtering` يُخفي بطاقات `visibility: 'admin-only'` (حصة الناظر/الواقف/ريع) + يُضيف `AccountantDashboardView` (5 بطاقات تشغيلية + متأخرات + تحصيل شهري) | يستفيد تلقائياً من تنظيف لوحة الناظر؛ **يجب التأكد** أن البطاقات المتبقية له ذات قيمة ولا تتعارض مع `AccountantDashboardView`. |
| **لوحة الناظر** | 13 بطاقة `stats` + 4 بطاقات `KPI` + Heatmap + جدول إجراءات + رسوم + مقارنة سنوات + عقود حديثة → **مكدّسة** | الهدف الرئيسي للموجة D. |
| **لوحة الواقف** (`WaqifDashboard`) | `WaqifFinancialSection` يعرض: إجمالي الدخل / إجمالي المصروفات / الريع القابل للتوزيع — تكرار صريح مع التقارير | تنظيف إضافي **لم يكن في الخطة السابقة**. |
| **صفحة العقارات** (`PropertiesPage`) | `PropertySummaryCards` فيها بطاقتان ماليتان (المخصص، المسدّد) إضافة للتشغيلية | حذف الماليتين فقط. |
| **صفحة العقود** | تبويبات: عقود / استحقاقات / **فواتير الدفعات** / **تقرير التحصيل** | الموجة E تنطبق كما خُطّط. |

---

## الموجة C — صفحة العقارات (الناظر + المستفيد)

**ملفات**: `PropertySummaryCards.tsx`, `PropertiesViewPage` المستفيد.

- **يُحذف**: بطاقتا «المخصص للسنة (allocated)» و«المُسدَّد للسنة».
- **يُبقى**: عدد العقارات، إجمالي الوحدات، المؤجَّرة، الشاغرة (4 بطاقات تشغيلية بحتة).
- **يُضاف**: شريط رابط واحد: *«التفاصيل المالية → التقارير المالية / الفواتير»*.

## الموجة D — لوحة الناظر (مع الأثر التلقائي على المحاسب)

**ملف المصدر**: `useAdminDashboardStats.ts` (مصفوفة `allStats`) + `AdminDashboard.tsx`.

### يُبقى في `stats` (8 بطاقات بدل 13)
1. إجمالي العقارات (تشغيلي)
2. العقود النشطة
3. الإيرادات التعاقدية للسنة
4. إجمالي الدخل الفعلي
5. إجمالي المصروفات
6. صافي الريع (مع YoY)
7. المستفيدون النشطون
8. التدفق النقدي الصافي (للناظر فقط)

### يُحذف من اللوحة الرئيسية (متوفّر في صفحات الاختصاص)
| بطاقة | البديل |
|---|---|
| المتاح للتوزيع | `/dashboard/distributions` |
| حصة الناظر | `/dashboard/accounts` |
| حصة الواقف | `/dashboard/accounts` |
| ريع الوقف | `/dashboard/accounts` |
| نسبة التوزيع الفعلي | `/dashboard/distributions` |

### KPI Panel (4 → 2)
- **يُبقى**: نسبة التحصيل، معدل الإشغال.
- **يُنقل إلى الاختصاص**: متوسط الإيجار → `usePropertiesSummary` (شارة تشغيلية)؛ نسبة المصروفات → `ExpensesPage` (بطاقة رأس).

### `FiscalYearWidget`
- يبقى كما هو (مؤشر سنة + إيراد تعاقدي + محصَّل) — هو المُلخّص التنفيذي المطلوب.

### `CollectionSummaryCard` + `CollectionHeatmap`
- يبقى (نظرة تحصيلية موحَّدة عابرة للصفحات، مرجع بصري للناظر).

### `YearComparisonCard` + `DashboardCharts`
- يُنقلان لتبويب فرعي «التحليلات» داخل الصفحة الرئيسية (لا يُحذفان، يُطوَيان بزر افتراضي مغلق) لتفريغ الواجهة.

### أثر على المحاسب
- بعد تقليص `stats` لا تحتاج فلترة `admin-only` لأن هذه البطاقات تُحذف للجميع. تبقى فلترة جدول `PendingActionsTable` كما هي.
- `AccountantDashboardView` يبقى دون تعديل (هو اختصاص المحاسب).

## الموجة E — إعادة المحاذاة الوظيفية

1. **نقل تبويب «تقرير التحصيل»** من `ContractsPage` إلى `IncomePage` كتبويب جديد، مع الإبقاء على نفس مكوّن `CollectionReport` (تغيير مستهلك واحد).
2. **توحيد تبويب «فواتير الدفعات»**: يُستبدل بعرض موجز + زر «الانتقال إلى الفواتير الضريبية» يحمل فلتر العقد عبر query string. الكود التفصيلي للفواتير يبقى في `InvoicesPage` فقط.
3. **صفحة العقود بعد التنظيف**: تبويبان فقط = العقود + الاستحقاقات.

## تنظيف لوحة الواقف (إضافة جديدة بعد التحقق)

**ملف**: `WaqifFinancialSection.tsx`.
- **يُحذف**: إجمالي الدخل، إجمالي المصروفات، الريع القابل للتوزيع (موجودة في صفحة التقارير المالية للواقف).
- **يُبقى**: مؤشر السنة + الرسوم العامة (`WaqifChartsInner`) + الإحصاءات العامة المُتحكَّم بها عبر `app_settings`.
- **يُضاف**: زر «التقارير المالية الكاملة» (`/dashboard/reports`).

## ضمانات

- **بدون أي تغيير** على قاعدة البيانات / RPC / RLS / ZATCA.
- كل بطاقة محذوفة لها زر تنقّل صريح لصفحة الاختصاص.
- احترام `accountant-dashboard-filtering` و`public-stats-anonymization` و`beneficiary-dashboard-customization` (`isVisible`).
- تحديث اختبارات Vitest المتأثرة: `useAdminDashboardStats`, `usePropertiesSummary`, `useIncomePage`.

## الترتيب التنفيذي

1. **C** (العقارات — منخفض المخاطر).
2. **E** (نقل تقرير التحصيل وتوحيد الفواتير).
3. **D** (إعادة هيكلة لوحة الناظر — أعلى أثر بصري + يلتقطه المحاسب تلقائياً).
4. **F** (تنظيف لوحة الواقف).

اعتمد للبدء، أو حدِّد موجة بعينها لبدئها أولاً.
