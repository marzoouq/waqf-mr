# خطة: شجرة التدقيق المحاسبي + فصل أقسام بقية التقارير + إصدار وثيقة معتمدة

ينفذ بالترتيب، كل مرحلة بحارس انحدار: اختبار أحمر ← تنفيذ ← أخضر ← كسر متعمد ← أحمر ← استرجاع.

## المرحلة 1 — فصل الأقسام وفهرس المحتويات
- استكمال الفصل في: تقرير الحسابات الختامية (العقود، الإيرادات، المصروفات، المتأخرات، التوزيع، حصص المستفيدين)، تقرير المقارنة (الملخص، المقارنة الشهرية، الأقسام التالية)، كشف المستفيد الشامل (ملخص الحصة، الجداول، المالية)، والتقرير السنوي (كل نوع بند في صفحة).
- إضافة صفحة فهرس في البداية للتقارير متعددة الأقسام: يسجل كل قسم اسمه ورقم صفحته أثناء الرسم، ثم يُكتب الفهرس في الصفحة الأولى بعد اكتمال الملف (اسم القسم ← رقم الصفحة).
- أداة مشتركة واحدة للفصل والفهرس حتى لا يتكرر المنطق.
- مراجعة بصرية: تنزيل كل تقرير فعلياً وتحويله لصور ومراجعة كل صفحة (التقرير المجمّع والإفصاح ضمنها).

## المرحلة 2 — شجرة التدقيق المحاسبي (لوحة الناظر والمحاسب)
صفحة جديدة "شجرة التدقيق" تعرض لكل سنة مالية:

```text
القائمة الختامية (الحسابات)
├── إجمالي الإيرادات
│   └── لكل عقار ← لكل عقد ← فواتير الإيجار المسددة ← قيد الدخل ← سند القبض
└── إجمالي المصروفات
    └── لكل نوع مصروف ← المصروف ← سند الصرف (إن وجد) ← الفاتورة
```

- كل عقدة تعرض المبلغ ومجموع أبنائها، والفرق إن وُجد بلون تحذيري، مع رابط لفتح السجل.
- فحص تلقائي (دالة خادمية للقراءة فقط، للناظر والمحاسب) يعيد قائمة مخالفات:
  - فاتورة مسددة بلا قيد دخل، أو قيد دخل بلا فاتورة.
  - مبلغ القيد ≠ المبلغ المسدد في الفاتورة.
  - فاتورة مسددة بلا سند قبض.
  - سند صرف معتمد بلا مصروف أو بمبلغ مختلف.
  - مجموع الإيرادات/المصروفات ≠ ما في القائمة الختامية وقائمة الدخل والمصروفات.
  - سجلات مقيدة على سنة مالية غير سنة تاريخها.
- زر "تشغيل الفحص" + شارة حالة (سليم / عدد المخالفات)، وتصدير نتيجة الفحص PDF رسمي.
- لا تعديل على أي بيانات — قراءة ومطابقة فقط.

## المرحلة 3 — نموذج إصدار وثيقة معتمدة من لوحة الناظر
- صفحة "إصدار وثيقة معتمدة" (للناظر فقط): نوع الوثيقة (إفادة، خطاب، شهادة استحقاق مستفيد، إفادة سداد مستأجر)، الجهة الموجّه إليها، الموضوع، النص، المستفيد/العقد المرتبط اختيارياً.
- عند الإصدار: تُسجل في سجل الوثائق الحالي برقم مرجعي ورمز تحقق، ثم يُنشأ PDF رسمي بالترويسة والتاريخين الهجري والميلادي والختم والتوقيع وQR.
- صفحة التحقق الحالية تعرض نوعها ورقمها وتاريخها وحالتها دون بيانات شخصية.
- قائمة بالوثائق الصادرة مع إعادة التنزيل والإلغاء (الإلغاء يظهر في صفحة التحقق).

## التفاصيل التقنية
- الفصل/الفهرس: توسيع `startSectionPage` في `pdfLayout.ts` بسجل أقسام `{title,page}` وكتابة الفهرس قبل `finalizePdf` (صفحة محجوزة عبر `insertPage`/رسم لاحق على الصفحة 1).
- شجرة التدقيق: دالة `audit_reconciliation(fiscal_year_id)` SECURITY DEFINER تتحقق من `has_role` admin/accountant، تقرأ `payment_invoices`، `income`، `receipt_vouchers`، `expenses`، `disbursement_vouchers`، `accounts`. Data hook في `hooks/data`، page hook في `hooks/page`، الواجهة بلا منطق.
- الوثيقة المعتمدة: جدول `official_letters` (نص الوثيقة) مع RLS للناظر فقط وGRANTs، والتسجيل عبر `issue_document` القائمة؛ لا تعديل على صفحة التحقق إلا لعرض النوع الجديد.
- الهجرات تحتاج نشراً لتصل الموقع الحي.

## بوابات الجودة
`tsgo`، اختبارات PDF والحراس الجديدة، فحص التكرار، Playwright لتدفق الإصدار والتحقق وتشغيل الفحص، ومراجعة صور صفحات PDF.
