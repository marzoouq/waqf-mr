# متابعة المهام المفتوحة

كل خطوة تتبع بروتوكول حارس الانحدار: فحص أخضر قبل ← اختبار أحمر ← تنفيذ أدنى ← أخضر ← كسر متعمد ← استرجاع، ثم بوابة الجودة (tsgo، eslint، conventions، quality:dup، test، test:edge، audit:forensic).

## 1. اختبارات الصفحات المتبقية (41 صفحة)
- الدفعة أ: شاشات المستفيد المتبقية (الرسائل، الدعم، السلف، الإشعارات، الملف الشخصي).
- الدفعة ب: العقود والفواتير والتحصيل.
- الدفعة ج: الإدارة (المستخدمون، الإعدادات، السنوات المالية، التشخيص، صلاحيات الملفات).
- لكل صفحة: يظهر بلا خطأ، يحترم الدور، يعرض حالة فارغة/تحميل، ويختبر قاعدة عمل واحدة على الأقل في خطاف الصفحة.

## 2. وظائف PDF والذكاء الاصطناعي
- فصل المنطق النقي في `generate-invoice-pdf` و`generate-voucher-pdf` و`ai-assistant` و`auth-email-hook` و`mcp` إلى ملفات تحقق مستقلة.
- اختبارات: رفض غير المسجل، رفض الدور غير المخوّل، تحقق المدخلات، عدم تسريب الأسرار، وصياغة الرسائل للمساعد (المستخدم دائماً user).

## 3. أدوات الرصد
- مقارنة شكل PDF: توليد فاتورة وسند ثابتين ومقارنة صورة كل صفحة مع نسخة مرجعية (فرق مسموح صغير).
- رصد الأداء: سكربت يقيس زمن التحميل وحجم الحزم للصفحات الرئيسية ويفشل عند تراجع يتجاوز الحد المحفوظ.

## 4. يبقى معلّقاً (خارج قدرتي)
- وصول تحديثات قاعدة البيانات للموقع الحي: يحتاج منك النشر والموافقة على تحديثات قاعدة البيانات.
- إعادة تشغيل طابور البريد: مرتبط بنفس المزامنة.
- اختبار التدفق الكامل (عقد ← فواتير ← سداد ← إقفال سنة) يُشغَّل على نسخة الاختبار بحساب الناظر التجريبي فقط.

## الترتيب
1 ← 2 ← 3، مع تحديث قائمة المهام بعد كل دفعة وتقرير بالأرقام.
