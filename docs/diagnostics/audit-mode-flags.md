# أعلام URL للتحكم

| العلم | المثال | الأثر |
|-------|--------|-------|
| `?audit=1` | `/?audit=1` | تفعيل وضع تدقيق Lighthouse: يعطّل SW + realtime + polling، ويرفع staleTime |
| `?sw=off` | `/?sw=off` | إلغاء تسجيل أي Service Worker للجلسة الحالية |
| `Chrome-Lighthouse` UA | تلقائي | يُكتشف من user-agent ويُفعّل نفس سلوك `?audit=1` |

## ملاحظات

- الأعلام تطبَّق على مستوى الجلسة، تختفي عند تغيير الرابط.
- `?audit=1` يُمكن دمجه مع أي route آخر (`?audit=1&tab=reports`).
- `?sw=off` مفيد لو ظهر SW قديم لا يستجيب — يُلغي تسجيله ثم يُعيد التحميل.
