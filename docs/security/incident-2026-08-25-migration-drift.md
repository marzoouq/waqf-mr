# حادثة 2026-08-25 — انفصال قاعدة الإنتاج عن المستودع

## الملخّص

اكتُشف خلال الفحص الجنائي المؤسسي أن قاعدة بيانات **الإنتاج** كانت متأخرة عن
المستودع بخمس هجرات. آخر هجرة مطبَّقة في الإنتاج كانت `20260730132351`، بينما
المستودع يحتوي هجرات حتى `20260802143340`.

السبب: في منصّة Lovable تُطبَّق الهجرات على بيئة الاختبار فوراً، وتنتقل إلى
الإنتاج **عند النشر فقط**. لم يُنشر التطبيق بعد 2026-07-30، فبقيت هجرات أغسطس
غير مطبَّقة على الإنتاج طوال الوقت.

## الأثر الفعلي

| الهجرة غير المطبَّقة | الأثر في الإنتاج |
|---|---|
| `20260802072323` | سياسة `Authenticated users can view invoices` بقيت حيّة — أي مستخدم مسجّل يقرأ كل ملفات الفواتير |
| `20260802080619` | عمودا `ip_address`/`session_id` وجدول `blocked_ips` غير موجودين — تتبّع المستخدمين وحجب IP معطّلان |
| `20260802082257` | دوال مساندة ناقصة |
| `20260802082709` | قيد `access_log_event_type_check` القديم يرفض `invoice_download` — فشل تسجيل التنزيلات |
| `20260802143340` | `alert_rules` و `alert_incidents` غير موجودين — تبويب التنبيهات يفشل بـ 404 |

كما تسبّبت الحادثة في توثيق مضلِّل: تقرير `SECURITY-SCAN-2026-08-23.md` وصف
السياستين الواسعتين بأنهما "false positives" اعتماداً على قراءة بيئة التطوير
وحدها. صُحِّح التقرير في 2026-08-25.

## الإصلاح

1. هجرة 2026-08-25 تُسقط كل الأسماء القديمة للسياسات الواسعة بشكل idempotent
   وتضيف حارس `DO $$` يفشل الترحيل إن عادت أي سياسة قراءة على حاوية الفواتير.
2. **نشر التطبيق** لمزامنة مخطّط الإنتاج مع المستودع — هذه هي الخطوة التي
   تُطبِّق الهجرات الخمس المتأخرة.
3. اختبار انحدار `src/test/storagePolicyRegression.test.ts` يمنع رجوع أي سياسة
   قراءة على الحاوية عبر تاريخ الهجرات.

## منع التكرار

- بوابة جديدة: `npm run check:migrations` (`scripts/migration-drift-gate.mjs`)
  تقارن ملفات `supabase/migrations` بجدول `supabase_migrations.schema_migrations`
  وتفشل عند وجود فجوة.
- قاعدة تشغيلية: **أي هجرة أمنية غير منشورة = ثغرة حيّة.** الإصلاح الأمني لا
  يُعتبر منجزاً إلا بعد النشر، لا بعد تطبيق الهجرة على بيئة الاختبار.
- أي تحقّق أمني يجب أن يقرأ **بيئة الإنتاج** صراحةً، لا بيئة التطوير.
