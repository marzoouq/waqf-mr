# جرد دوال SECURITY DEFINER

آخر تحديث: 2026-08-25 — المرحلة 3 من الفحص الجنائي المؤسسي.

## الخلاصة

| المؤشر | القيمة |
|---|---|
| إجمالي دوال `public` | 112 |
| دوال `SECURITY DEFINER` قابلة للتنفيذ من `anon` | 5 (كلها مقصودة، انظر أدناه) |
| دوال `SECURITY DEFINER` قابلة للتنفيذ من `authenticated` | 79 (محمية داخلياً بـ `has_role`) |
| عروض `SECURITY DEFINER` | 1 (`contracts_safe` — مقصود لإخفاء PII) |

المشغّل `auto_revoke_anon_execute` يسحب تلقائياً صلاحية `EXECUTE` من `anon`
عن أي دالة جديدة، لذا القائمة العامة لا تنمو دون قرار صريح.

## الدوال المتاحة لغير المسجّلين (5) — مقصودة

| الدالة | لماذا يجب أن تكون عامة | الحماية |
|---|---|---|
| `get_public_stats()` | إحصاءات صفحة الهبوط | تُعيد أرقاماً مجمّعة فقط، وكل إحصائية يتحكم بها الناظر عبر `app_settings` (auto/manual/hidden) |
| `log_access_event(...)` | تسجيل محاولات الدخول الفاشلة قبل المصادقة | إدخال فقط، لا قراءة؛ `event_type` مقيّد بقيد CHECK |
| `check_rate_limit(...)` | تحديد المعدل على مسارات ما قبل المصادقة | تعمل على مفاتيح مُشتقّة، لا تُعيد بيانات مستخدمين |
| `get_rate_limit_count(...)` | قراءة العدّاد للمسار نفسه | تُعيد عدداً صحيحاً فقط |
| `lookup_by_national_id(...)` | تسجيل الدخول برقم الهوية | تُعيد بريداً مُقنَّعاً `***@***.com` قبل نجاح كلمة المرور |

## الدوال المتاحة للمسجّلين (79) — نمط الحماية

كل الدوال الإدارية (`admin_*`, `close_fiscal_year`, `execute_distribution`,
`reopen_fiscal_year`, `admin_block_ip`, `admin_unblock_ip` ...) تتحقق داخلياً
عبر `has_role(auth.uid(), 'admin'::app_role)` وترفع استثناءً عند الفشل. هذا
النمط مقصود: الصلاحية تُفحَص داخل الدالة لا عند الاستدعاء، لأن الدوال تحتاج
`SECURITY DEFINER` لتجاوز RLS التقييدي على الجداول المالية.

سحب `EXECUTE` من `authenticated` عن هذه الدوال يعطّل التطبيق (لا يوجد دور
وسيط في PostgREST)، لذا تحذيرات linter من نوع
`0029_authenticated_security_definer_function_executable` **مقبولة بوعي**
شرط بقاء فحص `has_role` داخل كل دالة.

## قواعد ملزمة لأي دالة جديدة

1. أي `SECURITY DEFINER` جديدة تبدأ بـ `SET search_path = public`.
2. أي دالة تلمس بيانات مالية أو PII تفحص `has_role` في أول سطر منطقي.
3. لا تُمنح `EXECUTE` لـ `anon` إلا بإضافة صفّ إلى جدول "الدوال العامة" أعلاه
   مع تبرير مكتوب.
4. أي دالة تُعيد PII تُعيدها مُقنَّعة قبل المصادقة الكاملة.
