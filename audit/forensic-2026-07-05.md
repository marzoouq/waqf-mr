## 3. البند المتبقّي (P1)

**`.env` متعقّب في git.**

- تحقّق: `git ls-files | grep -E '^\.env$'` → موجود.
- المحتوى: `VITE_SUPABASE_URL` + `VITE_SUPABASE_PUBLISHABLE_KEY` — مفاتيح عامة (publishable/anon)، مُصمّمة للشحن في bundle المتصفح.
- **لا أسرار حقيقية للتدوير.**
- `SUPABASE_SERVICE_ROLE_KEY` وكلمة مرور DB **غير متوفّرة** على Lovable Cloud (لا وصول للـ dashboard).
- الإصلاح الوحيد (يدوي على جهاز المطوّر):
  ```bash
  git rm --cached .env
  git commit -m "chore: untrack .env (keep in .gitignore)"
  git push
  ```
- بعد ذلك، `.gitignore` سيمنع عودته، وبوابة `.husky/pre-push` §0/2 سترفض أي محاولة مستقبلية.
